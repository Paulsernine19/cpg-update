HMCAS CPG v2.6 Update Training
==============================

How to open
-----------
1. Unzip this folder (keep all the sub-folders next to index.html).
2. Double-click index.html. It opens in your web browser (Chrome or Edge recommended).

Folders
-------
index.html  The whole course (all four modules, hands-on activities, quick reference).
brand/      HMCAS logos
tx/         TXA preparation activity photos, avatar and video
th/         Newborn thermal care activity photos
rx/         Newborn resuscitation, code clock and spinal stretcher equipment photos

Notes
-----
- Works offline. With an internet connection it also loads the course fonts; without one it uses the system font.
- Progress is saved in the browser on that computer only. It is not an official training record.
- To host it for a team, upload the whole folder to any web server or intranet site and share the link to index.html.
- Clinical-review draft: content checked against the approved HMCAS CPG v2.6 (2026), awaiting education-lead sign-off.
